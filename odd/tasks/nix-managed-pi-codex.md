## Goal
Make Pi and Codex available from locked nixpkgs-unstable on a new NixOS install, while preserving mutable user authentication, sessions, extensions, and the upstream-owned Gentle AI and Engram installations.

## Scope and constraints
- Change the executable owner for Pi and Codex to Home Manager packages.
- Keep old standalone/npm binaries and all user data untouched; ensure the Nix profile has PATH priority in Fish and Home Manager sessions.
- Preserve npm prefix and PATH availability for remaining npm tools such as CodeGraph.
- Do not add an automatic Gentle AI installer to `just switch`; that is a separate proposal requiring review of its effects and lifecycle.
- Preserve pre-existing worktree changes, especially `flake.lock`; do not activate or commit without explicit user authorization.
- Testing mode: ordinary configuration checks, no TDD runner applies to declarative Nix modules.
- Delivery strategy: ask-on-risk; expected authored diff under ~150 lines, excluding existing changes.
